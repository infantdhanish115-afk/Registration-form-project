🧾 Registration Form

This is a responsive Registration Form built using HTML, Tailwind CSS, and JavaScript.
It allows users to enter their personal details such as name, email, password, gender, and phone number with form validation.
Once all fields are filled correctly and terms are accepted, a success message appears confirming the registration.

⚙️ Features

Responsive and modern UI using Tailwind CSS

Input validation with JavaScript

Password confirmation check

Terms and conditions agreement checkbox

Dynamic “Registration Successful!” message

💻 Technologies Used

HTML5

Tailwind CSS

JavaScript
